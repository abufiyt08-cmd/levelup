Program latihan

Aturan progres

• Pemanasan umum 5–8 menit dan set pemanasan bertahap.

• Gerakan utama 2–3 set, umumnya 6–12 repetisi; aksesori 10–15 repetisi.

• Sisakan 2–3 repetisi sebelum gagal pada sebagian besar set.

• Istirahat 2–3 menit untuk gerakan besar, 60–120 detik untuk aksesori.

• Naikkan beban sedikit jika semua repetisi tercapai dengan teknik baik.
